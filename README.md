# TRAPPIST-1 Explorer

I built this small browser prototype to explore the seven known TRAPPIST-1
worlds. Open `index.html` in a modern browser, or serve this directory with
any static web server.

## GitHub Pages

Every push to `main` deploys the current game to GitHub Pages. In the
repository's **Settings → Pages**, set the source to **GitHub Actions** once,
then visit `https://jpcwin11.github.io/Trappist/` after a successful deployment.

## Controls

- **WASD / arrow keys:** fly, walk, or drive
- **L:** land when I'm close to a planet; launch when I'm on the surface
- **R:** enter or exit the rover after landing
- **Space:** scan the current location
- **F:** fire the exosuit pulse weapon while exploring on foot

I fly near any labeled world and land to explore it on foot or in the rover.
